# Code of conduct

MaintenGraph is a professional engineering project. Participants must be
respectful, constructive, technically honest and careful with operational data.

Harassment, discrimination, threats, deliberate disruption, impersonation,
misleading certification claims, credential sharing, doxxing and publication
of confidential or customer information are unacceptable.

Project maintainers may edit, remove or reject contributions and interactions
that violate these expectations, and may temporarily or permanently restrict
participation. Security concerns must use private vulnerability reporting.

Enforcement decisions are made by the repository owner, Mohammad Allatayfeh.
Because no public conduct email is designated, report non-security conduct
concerns through a minimal GitHub issue that contains no sensitive details and
requests private follow-up.

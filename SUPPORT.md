# Support policy

MaintenGraph is community-supported open-source software provided without a
support SLA.

- Read the [README](README.md) and [rule reference](docs/RULE_REFERENCE.md).
- Search existing issues before opening a new one.
- Use the structured bug or feature form and reproduce problems with synthetic
  data only.
- Use GitHub private vulnerability reporting for security concerns.

Never attach a real asset hierarchy, customer file, credential, contract,
manual, drawing, screenshot containing operational data, or other confidential
material to an issue or pull request. Maintainers may close or redact unsafe
submissions but cannot guarantee removal from Git history or third-party caches.

Questions about a specific CMMS, migration engagement, data correction service
or import certification are outside the free project's support scope.
